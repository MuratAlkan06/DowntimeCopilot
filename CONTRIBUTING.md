# Contributing

This project was built as a gated, single-developer overnight build for SpartHill Hacks 2026. The workflow below is the one that actually operated and remains in force.

## Workflow
- Branch per slice of work (`feat/<topic>`, `fix/<topic>`, `docs/<topic>`), opened from a freshly pulled `main`.
- Every change lands through a pull request into `main`, squash-merged with `--delete-branch`. `main` must always run `make demo`.
- Non-admin merges to `main` require one approving review (repository ruleset). CI — the secret/probe guard and the test suite — must be green on the exact head before any merge.
- Commits are Conventional Commits: lowercase, imperative, ≤72-character subject, no trailing period. No AI-attribution trailers of any kind (owner ruling, 2026-10-09).

## Credentials and honesty
- Credentials live only in the git-ignored `.env` (`source .env`); never in code, docs, logs, or fixtures. `tools/guard.sh` runs before every commit and in CI.
- `tools/bedrock_probe.py` is distributed by direct message and is never committed.
- Everything that touches a model is logged with model, tokens, latency, and estimated cost.
- `RESULTS.md` is generated by `make evals` from real runs only and is never hand-edited.
